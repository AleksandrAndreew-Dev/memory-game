# Memory Game — Star Wars Edition

Классическая игра «Найди пару» в стилистике Star Wars.
Переворачивай карточки, находи совпадающие пары персонажей и запоминай их цитаты.

## Возможности

- 🃏 **8 персонажей** Star Wars — 16 карточек (каждая пара дублируется)
- 🔀 **Случайная перетасовка** при каждой новой игре (Fisher–Yates shuffle)
- 📊 **Счётчик ходов и пар** — обновляется в реальном времени
- 🏆 **Таблица лидеров** — топ-10 результатов сохраняются в `localStorage`
- 🎉 **Модальное окно победы** — со случайным персонажем, его цитатой и количеством ходов
- 📱 **Адаптивная вёрстка** — 4 колонки на десктопе, 2 на мобильных
- ⚡ **Блокировка кликов** во время «закрытия» неправильной пары (1 секунда)
- 🎨 **Золотая стилистика** Star Wars с анимациями и hover-эффектами
- 🖼️ **Рубашка карточки** — логотип Star Wars вместо отдельного изображения

## Демо

| Элемент      | Описание                                                |
| ------------ | ------------------------------------------------------- |
| Игровое поле | Сетка 4×4 (16 карточек)                                 |
| Ходы         | Считаются каждый раз, когда открывается вторая карточка |
| Пары         | `найдено / 8`                                           |
| Победа       | Модальное окно с цитатой персонажа и кнопкой «New game» |
| Лидеры       | Топ-10 результатов по количеству ходов (меньше — лучше) |

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/AleksandrAndreew-Dev/memory-game.git
cd memory-game
```

### 2. Запустить локальный сервер

Проект не требует сборщика — это чистый ES-модульный JavaScript.
Но из-за `fetch('./data/data.json')` и ES-модулей **нельзя открывать `index.html` напрямую через `file://`** — нужен локальный сервер.

#### Вариант 1: Live Server (VS Code)

1. Установи расширение **Live Server**
2. Открой `index.html` → правый клик → **Open with Live Server**

#### Вариант 2: Python

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

#### Вариант 3: Node.js

```bash
npx serve .
```

## Как играть

1. Нажми **New game**, чтобы начать (или перезапустить) игру.
2. Кликай по карточкам — они переворачиваются, показывая персонажа.
3. Открой **две карточки**:
   - если персонажи совпали — пара остаётся открытой и подсвечивается золотом;
   - если нет — обе закрываются через 1 секунду.
4. Найди все **8 пар**, чтобы победить.
5. После победы:
   - результат сохраняется в таблицу лидеров;
   - показывается модальное окно со случайным персонажем и его цитатой.
6. Кнопка **Leaders** — таблица топ-10 результатов.

> 💡 Чем меньше ходов — тем выше место в таблице лидеров.

## Сборка SCSS

```bash
npm install
npm run sass        # watch-режим
npm run sass:build  # минифицированная сборка
```

Скрипты из `package.json`:

| Команда              | Что делает                                             |
| -------------------- | ------------------------------------------------------ |
| `npm run sass`       | `sass --watch scss/main.scss:css/style.css`            |
| `npm run sass:build` | `sass scss/main.scss:css/style.css --style=compressed` |

## Технологии

- **HTML5** — семантическая разметка, `<dialog>` для модалок
- **CSS3 / SCSS** — Grid, `aspect-ratio`, `::before`, медиазапросы, партиалы
- **JavaScript (ES2022)** — ES-модули, top-level `await`, optional chaining, `dataset`
- **localStorage** — хранение таблицы лидеров
- **Sass** — препроцессор для стилей (devDependency)

---

## Архитектурные заметки

- **Состояние** хранится в одном объекте `state` (`js/state.js`) — это упрощает отладку и сброс.
- **Компоненты** — чистые функции, создающие DOM-узлы (`createElement` из `helpers.js`).
- **Логика игры** вынесена в `game.js` и не знает о конкретных DOM-элементах, кроме `.board` и `.stats`.
- **Модалка** — singleton: `getModal()` возвращает один и тот же `<dialog>`.
- **Данные** загружаются один раз при старте через `fetch` в `data.js`.
